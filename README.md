# Kalel Uthuman — Personal Profile Website

A static, mobile-friendly profile site for GitHub Pages.

## Publish for free

1. Create/sign in to a GitHub account at https://github.com/
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
3. Upload `index.html` and `favicon.svg` from this folder to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, then select branch `main` and folder `/ (root)`. Save.
6. Wait for the deployment to finish, then open `https://YOUR-GITHUB-USERNAME.github.io/`.

Official guide: https://docs.github.com/en/pages/quickstart

## Before publishing / after publishing

- Review the biography and project descriptions so every statement is accurate.
- Replace the generic GitHub, LinkedIn, and YouTube links with your actual profiles, or remove any you do not use.
- Add real project repositories, photos, demos, and dates as they become available.
- Do not publish private contact details, ID documents, passwords, or anything you do not want public.
- Public repository content and the published site can be seen by anyone.

## Help Google discover the site

1. Open https://search.google.com/search-console/ and add your full GitHub Pages URL as a URL-prefix property (for example `https://YOUR-GITHUB-USERNAME.github.io/`).
2. Complete the available ownership verification steps.
3. Use URL Inspection to inspect the home page URL, then choose **Request indexing** if offered.
4. Search Console may take time to process the site; indexing is not guaranteed.
5. Share the same official profile URL from your public professional accounts and link those accounts back to the site.

## Notes

- No paid domain is required.
- GitHub Pages is static hosting; this page does not have a server-side contact form.
- The page includes basic title, description, Open Graph metadata, and Schema.org Person structured data. Structured data does not guarantee a knowledge panel or AI citations.
